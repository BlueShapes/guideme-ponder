# アイテムの解説入口の監査（2026-10-23）

基準コミットは`c11d7de82a66e064ec0de328f070f36c5635d10c`です。対象はAE2 19.2.18（NeoForge 1.21.1）／15.4.11（Forge 1.20.1）と、既に対応・導入しているOmni Cells、Bigger AE2、AE2 Things、MEGA Things、MEGA Cellsです。MEGA Cellsの固定版は4.11.0／2.4.6です。新しいMODは追加していません。

## 独立した対象一覧

AE2の`AEItems`・`AEBlocks`・`AEParts`の初期化、実際の17色のケーブル・16色の通常／発光ペイントボールのループ、同梱ガイドの`item_ids`と本文参照を照合しました。アドオンは各固定JARの登録実装・条件・元ガイドを照合しました。元ガイドの古い記述と実装が違う場合は実装を優先しています。例として、液体セルの種類上限は両固定版の実装に従って18種類を保持しました。

既存の教材登録は変更前の入口を測るために使い、期待する対象IDの発見には使っていません。全件のID・変更前後・機能群・元ガイドの関連ページ・固定JARのSHA-256・除外理由は[item-coverage.json](item-coverage.json)にあります。`python tools/item_coverage.py`は、この独立した対象一覧と現在の定義を比較します。実レジストリと標準W操作の検査は、配布JARに含めない`item_coverage.json`の検証用フィクスチャを使います。

最初の教材は、ガラス／被覆が`first_network`、通常スマートが`network_connections`、被覆高密度が`dense_branching`、スマート高密度が`controller`です。系統間の機能・コースは保ち、同系統17色のコースとタグを一致させました。色を統一するためにItemStackのデータを消去する処理はありません。

スマートケーブルの表示は、両JARの`CablePart.getVisualChannels`、`CableBuilder.addSmartConnection`／高密度用接続描画と段階テクスチャで確認しました。標準設定では通常が1本につき1チャネル、高密度が4チャネル刻みの切り上げです。高密度の8本点灯は29～32チャネルであり、32ちょうどとは断定しません。容量設定変更時は尺度が変わり、無制限設定では使用があれば全点灯します。

スタッフは蓄電量が厳密に300 AEを超えると追加放電し、300 AEを消費します。追加魔法攻撃の基本ダメージ6は通常打撃とは別処理です。教材は仮想ワールドの生きた対象へ被弾アニメーションと放電を示し、対象の体力を改変して確定総ダメージを演出しません。空・300・1000 AEの入力スタックで同じ正しい教材を選び、蓄電情報を保持することを検査します。

## 条件付き対象と除外

- 本体の内部・開発用候補はNeoForgeで9、Forgeで8 IDです。ケーブルの集約ホスト`ae2:cable_bus`、ペイントの内部ブロック`ae2:paint`、データ付き内部資源表現`ae2:wrapped_generic_stack`、空間境界、欠損コンテンツ、開発用ツール等を、実際の機能とクリエイティブ出力から区別しました。`debug_card`が他の全ツールと同じ設定条件だとは主張しません。
- 元の4アドオンでは、未導入連携がNeoForgeで24、Forgeで15 IDです。Bigger AE2の電力・化学・経験値・Source連携や、MEGA Thingsの化学DISK等が対象です。Mekanismだけで`appmek`の代用にはなりません。
- MEGA Cellsの連携候補はNeoForgeで56のダミー、Forgeで37の条件付き未登録IDです。両版の登録方法が違うため、単に「MODがないのでそのIDもない」とは扱いません。Forgeの`megacells:decompression_pattern`はモジュール内部で生成するパターンで、通常の空パターンとは別の内部1 IDです。
- `appflux`・`appmek`・`appex`・`arseng`・`appbot`・`appliede`・`appliedsoul`等の対象プロバイダーを将来追加したときは再監査が必要です。未導入時の候補を、通常のアイテム／液体セルの教材へ無理に関連付けていません。
- MEGA Cellsの通常セル、MEGA ThingsのDISK、Omni混合セル、AE電力セル、クラフトCPUのメモリーを区別しました。MEGA Cellsの携帯アイテムセルは段階によって種類上限が27～63に変わるため、一律63や種類無制限とは書いていません。
